## Fixed font loading for all languages
- **Root cause:** `next/font/local` with `variable` creates a hashed font-family name. The lazy `@font-face` rules in globals.css used a different family name (`"MiSans Fallback"`), so they were treated as a completely separate font — weights never connected.
- **`app/layout.jsx`:** Now loads ALL 8 MiSans weights (Thin through Heavy) via `next/font/local` under `--font-misans`. Added a separate `--font-khmer` variable (preload: false) with Khmer OS font fallbacks.
- **`app/globals.css`:** Removed broken lazy `@font-face` rules. Added `"Khmer Fallback"` with `unicode-range: U+1780-17FF` to target only Khmer script glyphs, falling back to local Noto Sans Khmer / Khmer OS / Leelawadee UI.
- **`tailwind.config.js`:** 
  - `font-display`, `font-sans`, `font-mono`: `var(--font-misans)` → system-ui → sans-serif
  - `font-sc`: adds PingFang SC + Microsoft YaHei as CJK fallbacks
  - `font-khmer`: `var(--font-khmer)` → Khmer Fallback → Noto Sans Khmer → Khmer OS → Leelawadee UI
- MiSans covers Latin + CJK. Khmer script uses the separate `font-khmer` stack so when MiSans lacks a Khmer glyph, the browser falls through to OS-native Khmer fonts.
